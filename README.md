# Tugas 1 - Merancang Antarmuka (UI) Dasar Aplikasi Mobile

Aplikasi **Mengenal Negara dan Bendera ASEAN** berbasis Android yang dikembangkan menggunakan Jetpack Compose (Material 3) di Android Studio.

## 📱 Fitur & Layar Aplikasi

1. **Layar 1 (Tab Negara ASEAN)**: Halaman daftar 10 negara anggota ASEAN dengan sapaan ramah "Halo Dewi!" dan komponen Card interaktif untuk tiap negara.
2. **Layar 2 (Tab Bendera Negara)**: Halaman detail bendera dari setiap negara ASEAN lengkap dengan sebutan/deskripsi benderanya (contoh: Indonesia — Merah Putih).

## 🛠️ Komponen UI Dasar yang Digunakan

* **Layout & Container**: Scaffold, Column, Row, LazyColumn
* **View / Components**: Text, Card, NavigationBar, NavigationBarItem, Icon
* **Configuration**: Jetpack Compose (Material 3), build.gradle.kts (Compile SDK 35, Min SDK 26)

## 🚀 Cara Menjalankan Aplikasi

1. Clone repositori & buka di Android Studio: `git clone https://github.com/dewistfatiha-max/latihandewi1.git`
2. Sync Gradle & jalankan langsung ke HP / Emulator via Android Studio (`Shift + F10`) atau via Terminal: `./gradlew installDebug`
